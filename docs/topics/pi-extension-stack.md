# Pi Extension Stack

Main consume la allowlist global de Pi y `/flow` desde `C:/dev/os`; no duplica
el inventario. CodeMapper/FFF orientan, Lens/LSP diagnostican, Advisor revisa
riesgo, web investiga y Ask User controla gates. Las rutas se declaran en el
brief y no generan perfiles o runtime state locales.

Taskflow, Council, planner, until-done, dgoal y aliases lifecycle están retirados.
Instalar o modificar paquetes requiere autorización y backup global.
